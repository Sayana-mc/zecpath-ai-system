# Day 58 — Advanced Feature Proposal

A local Python proposal and rule-based candidate coaching prototype for the Zecpath AI Hiring System.

## Run
From the parent directory `zecpath-ai-system`:

```powershell
python -m day58_advanced_feature_proposal.src.main
python -m unittest discover -s .\day58_advanced_feature_proposal\tests -v
```

## Outputs
- `output/ai_roadmap_and_innovation_proposal.md`
- `output/innovation_proposal.json`
- `output/candidate_coaching_preview.json`

## Important limitations
This is a proposal and local prototype, not a production AI model. Coaching suggestions are rule-based. Video analysis is not implemented. Emotion or personality inference is excluded from hiring decisions. Human review is required and automatic rejection is disabled.
