\# ATS Live Demo Guide



\## Objective



To demonstrate the complete ATS candidate evaluation workflow.



\## Input



The system receives candidate resume information and a target job description.



\## Processing Workflow



1\. Resume Input

2\. Text Extraction

3\. Text Normalization

4\. Section Processing

5\. Skill Detection

6\. Experience Detection

7\. Candidate Profile Creation

8\. Job Requirement Processing

9\. Candidate-Job Matching

10\. ATS Scoring

11\. Candidate Ranking

12\. Final Decision
