\# Day 35 Communication Scoring Formula



\## Objective



The communication evaluation module assigns a normalized communication

score between 0 and 100.



\## Parameters



| Parameter | Maximum Score |

|---|---:|

| Fluency | 20 |

| Grammar Quality | 20 |

| Vocabulary Range | 15 |

| Clarity | 20 |

| Answer Structure | 15 |

| Filler Control | 10 |

| Total | 100 |



\## Formula



Communication Score =



Fluency

\+ Grammar Quality

\+ Vocabulary Range

\+ Clarity

\+ Answer Structure

\+ Filler Control



Maximum possible score = 100.



\## Fluency



Fluency is estimated using response length and sentence continuity.



\## Grammar Quality



Grammar is evaluated using basic sentence-pattern checks.



\## Vocabulary Range



Vocabulary range is estimated using the ratio of unique words

to total words.



\## Clarity



Clarity considers whether the answer contains enough information

and multiple meaningful sentences.



\## Answer Structure



Structured answers with multiple sentences receive higher scores.



\## Filler Words



The system detects common filler expressions such as:



\- um

\- uh

\- like

\- actually

\- basically

\- you know

\- sort of

\- kind of



Fewer filler words result in a higher filler-control score.



\## Bias Reduction



The scoring system focuses on observable communication characteristics

rather than personal attributes.



The final score is normalized to a 0-100 scale.



\## Interpretation



0-39   -> Weak communication signal

40-59  -> Developing communication signal

60-79  -> Good communication signal

80-100 -> Strong communication signal



These ranges are indicators for screening analysis and should not be

treated as a standalone hiring decision.
