\# Day 38 – Aptitude Logic Design



\## Objective



Add cognitive and situational evaluation into the HR interview system.



\## Aptitude AI Design



The system contains reasoning-based and situational judgment questions.



Question categories:

\- Logical Reasoning

\- Situational Judgment

\- Problem Solving



Each question contains:

\- Question ID

\- Category

\- Question

\- Ideal answer structure



\## Logical Reasoning Scoring Model



The logical reasoning model evaluates:



1\. Logic

2\. Clarity

3\. Problem-solving ability



The parameters are converted into a normalized 0–100 score.



\## Scenario Evaluation Framework



Situational answers are evaluated using:



\- Decision making

\- Communication

\- Problem solving



The indicators are converted into an overall scenario score.



\## Output



The system generates:



aptitude\_evaluation.json



The output contains:

\- Question ID

\- Category

\- Candidate answer

\- Logical reasoning score

\- Scenario score

\- Parameter-level scores



\## Deliverables



1\. Aptitude AI Design

2\. Logical Reasoning Scoring Model

3\. Scenario Evaluation Framework
