# Day 56 — Full System Simulation

Python 3.10+; standard library only.

Run from the repository root:
```powershell
python -m day56_full_system_simulation.src.main
python -m unittest discover -s .\day56_full_system_simulation\tests -v
```

Generated outputs:
- `output/end_to_end_test_report.json`
- `output/end_to_end_test_report.md`
- `output/performance_analysis.json`
- `output/improvement_recommendations.md`

All data are synthetic. ATS uses keyword coverage, not a trained model. Human judgments are simulation labels, not verified ground truth. Human review is mandatory and automatic rejection is disabled.
