\# Day 47 – Technical Evaluation Report Format



\## 1. Candidate Information



\- Candidate ID:

\- Candidate Name:

\- Job Role:

\- Interview Date:

\- Evaluated Skills:



\## 2. Overall Technical Evaluation



\- Overall Technical Score: /100

\- Questions Evaluated:

\- Evaluation Method: Question-type weighted rubric

\- Report Status: Completed / Pending Review



\## 3. Skill-Wise Scoring Breakdown



For each skill, report:



\- Skill Name

\- Number of Questions

\- Average Technical Score

\- Question Difficulty

\- Areas Requiring Improvement



\## 4. Question-Level Scoring



Each question is evaluated using:



| Parameter | Score Range |

|---|---|

| Accuracy | 0–5 |

| Depth of Explanation | 0–5 |

| Logical Reasoning | 0–5 |

| Real-World Applicability | 0–5 |



The parameter scores are combined using the configured weights for the question type to produce a score out of 100.



\## 5. Answer Depth Classification



\- \*\*Shallow:\*\* Limited detail or reasoning according to the configured demo rules.

\- \*\*Moderate:\*\* Some explanation, reasoning, or practical detail.

\- \*\*Deep:\*\* Sufficient detail, reasoning, and application signals according to the configured demo rules.



These labels are heuristic classifications, not proof of technical mastery.



\## 6. Explainable Feedback



For every question, include:



\- Technical score

\- Parameter-level scores

\- Reason for the score

\- Strengths

\- Improvement suggestions



\## 7. Evaluation Limitations



The current implementation uses manually supplied parameter scores and rule-based answer-depth classification. It does not independently verify factual accuracy or perform semantic AI evaluation.



\## 8. Final Review



A reviewer should validate the candidate's answers, scoring evidence, and skill-level results before making a hiring decision.
