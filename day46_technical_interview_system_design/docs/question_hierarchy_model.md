\# Technical Interview Question Hierarchy



\## Level 1 – Introduction



Purpose:



Understand the candidate's technical background.



Examples:



\- Tell me about your technical background.

\- Which technologies have you worked with?



Difficulty: Basic



\---



\## Level 2 – Experience-Based



Purpose:



Understand real project and implementation experience.



Examples:



\- Explain a project you developed.

\- What technical challenges did you face?



Difficulty: Basic to Intermediate



\---



\## Level 3 – Conceptual



Purpose:



Test technical knowledge and fundamentals.



Examples:



\- Explain OOP concepts.

\- Explain database indexing.

\- Explain machine learning overfitting.



Difficulty: Basic to Advanced



\---



\## Level 4 – Scenario-Based



Purpose:



Evaluate practical problem solving.



Examples:



\- How would you debug a production API failure?

\- How would you handle model overfitting?



Difficulty: Intermediate to Advanced



\---



\## Level 5 – System Design



Purpose:



Evaluate architecture and scalability thinking.



Examples:



\- Design a scalable API.

\- Design an ML inference system.



Difficulty: Advanced



\---



\## Progression



Introduction

→ Experience

→ Conceptual

→ Scenario

→ System Design

→ Evaluation
