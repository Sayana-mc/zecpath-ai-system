\# Day 11 – Education \& Certification Parsing



\## Objective



To automatically extract academic qualifications and professional certifications from resumes.



\## Features



\- Degree type extraction

\- Field of study extraction

\- Institution extraction

\- Graduation year extraction

\- Certification extraction

\- Certification normalization

\- Certification category classification

\- Education relevance scoring

\- Structured academic profile generation



\## Input



Day 8 segmented resume JSON files.



\## Output



Structured academic profile JSON files.
