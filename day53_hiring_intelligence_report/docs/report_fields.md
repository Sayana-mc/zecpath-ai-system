

\# Hiring Intelligence Report Fields



\## Candidate profile



Candidate ID, session ID, candidate name, target role, assessment status.



\## Evaluation results



\- ATS summary and score.

\- Screening results and score.

\- HR interview insights and score.

\- Technical interview performance and score.

\- Machine-test performance and score.



\## Candidate insights



Strengths and development areas are collected from supplied evaluation

notes and completed round scores using the configured thresholds.



\## Behavioral and integrity assessments



Each assessment contains status, summary, flags and supporting evidence.



\## Risk indicators



Incomplete rounds, incomplete behavior/integrity assessments and

recorded flags are presented for review.



\## Final recommendation



Decision category, unified score, evidence confidence, reasons,

review reasons, human-review requirement and advisory disclaimer.



\## Export formats



\- JSON: Structured report data for applications and integrations.

\- Markdown: Human-readable report suitable for review and conversion.
