

\# Export and Validation



\## JSON export



The JSON file preserves the report structure, candidate profile,

evaluation results, strengths, weaknesses, risk indicators and

recommendation.



\## Markdown export



The Markdown report includes a title, candidate profile, executive

summary, evaluation table, strengths, development areas, risk details,

recommendation, review checklist and disclaimer.



\## Validation



\- Validate scores on the 0-100 scale.

\- Validate required candidate identifiers.

\- Validate that assessment sections contain the expected data types.

\- Preserve missing-round indicators.

\- Verify recommendation reasons and review conditions.

\- Generate both export files.

\- Run unit tests and review the generated files.



\## Limitations



The output is a report generated from supplied data, not proof that

every assessment statement is accurate. A recruiter must verify the

underlying evidence before relying on the report.
