# Zecpath AI Data Dictionary

## Candidate ID

Unique identifier assigned to every candidate.

Example:

CAND001

## Job ID

Unique identifier assigned to every job description.

Example:

JD001

## Application ID

Unique identifier for a candidate's application to a particular job.

Example:

APP001

## Model Version

Identifies the AI model used for processing or prediction.

Example:

ats-model-v1.0

## Pipeline Version

Identifies the version of the data processing pipeline.

Example:

v1.0

## Timestamp

Records when a data processing event occurred.

Format:

ISO 8601

## Data Version

Identifies the version of the stored data structure.

Example:

v1

## Status

Represents the current processing or hiring state.

Examples:

uploaded
processing
completed
failed
shortlisted
rejected
selected
