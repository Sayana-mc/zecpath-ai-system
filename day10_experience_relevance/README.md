\# Day 10 – Experience Parsing \& Relevance Engine



\## Objective



To understand professional background and compute experience relevance for specific job roles.



\## Features



\- Company name extraction

\- Job title extraction

\- Employment date parsing

\- Employment duration calculation

\- Total experience calculation

\- Employment gap detection

\- Overlapping employment detection

\- Role-to-role similarity

\- Experience relevance scoring

\- Structured JSON output



\## Input



Day 8 labeled resume JSON files.



\## Output



Structured experience JSON files.



\## Main Modules



\- experience\_parser.py

\- relevance\_scorer.py

\- experience\_engine.py

\- main.py

python -m pytest -v tests

Run:



python -m src.main
